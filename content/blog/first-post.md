# Belajar Playwright dari Nol

Playwright adalah framework automation testing modern yang mendukung Chromium, Firefox, dan WebKit.

## Kenapa Playwright?

- Cepat
- Open Source
- Cocok untuk E2E Testing
- Mendukung TypeScript

## Kesimpulan

Playwright sangat cocok digunakan untuk automation testing modern.
